CH.02 / LEXICON

Every term on this page, explained simply

Written so it makes sense even if you've never touched AI tools before — no jargon left unexplained.

Parameterse.g. "7B"
Think of the AI as a giant machine with billions of tiny dials inside it. Each "parameter" is one dial, and training the AI is the process of turning all those dials to the right position. "7B" means 7 billion dials. More dials usually means the AI can understand and draw more complex things, but it also means a bigger file to download and more computer power needed to run it.
RGBA / Alpha Channel
Every pixel in a normal photo is made of Red, Green, and Blue light mixed together — that's "RGB". The "A" stands for Alpha, which is a fourth piece of information that says how see-through each pixel is. A PNG sticker with a transparent background (no white box around it) uses alpha. This model can generate images with that transparency built in, automatically.
Diffusion Model
A type of AI that creates images by starting with random TV-static-like noise, then slowly "cleaning it up" step by step until a real picture appears — kind of like how a sculptor starts with a rough block of stone and gradually removes bits until a statue appears.
DiT LayersDiffusion Transformer layers
The 32 separate "stages" the noisy image passes through on its way to becoming a finished picture. Each stage refines the image a little more — like an assembly line where every station adds one more improvement.
Attention"mixed-granularity attention"
This is how the AI decides what to focus on. If your prompt says "a red cat on a blue couch," attention is the mechanism that helps the AI connect the word "red" to the cat and not the couch. "Mixed-granularity" just means it can focus on both big-picture details and tiny fine details at the same time.
KV Cache"prefix KV cache reuse"
A memory shortcut. Instead of re-doing calculations it already finished, the AI saves ("caches") that work and reuses it. This is especially helpful when you give it multiple reference images, since it doesn't have to re-analyze the same image twice — it just makes things faster.
Reference Images
Photos you upload to show the AI what you want it to copy, combine, or edit — for example, "put the shirt from image 1 on the person in image 2." This model can take up to 10 of these at once.
Prompt
The text instructions you type to tell the AI what to make, like typing a search into Google, except here you're describing a picture instead of searching for a webpage.
Checkpoint
A saved, downloadable copy of the AI's fully-trained "brain" — basically the file you download that contains all those billions of dials already set correctly. Different checkpoints on this page are the same brain, just repackaged for different computers.
Diffusers
A free toolkit (made by Hugging Face) that programmers use to run AI image models with a small amount of Python code, instead of building everything from scratch.
ComfyUI
A program with drag-and-drop boxes and wires (like a flowchart) that lets you run AI image models by connecting pieces visually, without writing any code at all.
GGUF
A file format designed to shrink AI models down and make them run on regular laptops (using llama.cpp software), instead of needing an expensive data-center graphics card.
QuantizationQ2_K, Q4_K_M, Q6_K, Q8_0, INT4
A way of compressing an AI model by making its internal numbers less precise — similar to saving a photo as a smaller JPEG instead of a huge raw file. "Q8" keeps almost all the quality; "Q2" is much smaller but a bit blurrier in its results. It's a trade-off between file size and quality.
VRAM
The memory built into your graphics card (GPU), separate from your computer's regular RAM. AI models need to fully fit inside this memory to run — if your graphics card only has 8GB of VRAM, you need a version of the model small enough to fit in that space.
BF16
A specific way of storing the AI's numbers using 16 bits each — a middle ground that's smaller than the highest-quality format but still very accurate. Most "official" checkpoints are released in this format.
MLX
A toolkit made by Apple that lets AI models run efficiently on Mac computers with M-series chips (M1, M2, M3, etc.), instead of needing an Nvidia graphics card.
Distillation / Turbo"DMD", 4-step inference
Normally, generating an image takes dozens of small refining steps. A "turbo" or "distilled" model has been specially trained by a slower "teacher" model to get a similar-quality result in far fewer steps (like 4 instead of 40) — trading a little quality for a lot of speed.
Stepse.g. "40 steps"
How many times the AI refines the noisy image before calling it finished. More steps generally means more detail, but takes longer; fewer steps is faster but can look rougher.
Resolutione.g. "2048px"
How many tiny colored dots (pixels) make up the image, measured in width and height. 2048px means the image is 2048 dots wide — more pixels means a sharper, more detailed picture when you zoom in.
License"Qwen Research License"
The legal rulebook that says who's allowed to use this AI model and for what. Some licenses only allow personal or research use and restrict selling products made with the AI — always worth reading before using something commercially.
SpaceHugging Face Space
A free mini-website, hosted by Hugging Face, where you can try out an AI model directly in your browser — no downloading, no installing, no account required most of the time. The generator embedded above on this page is exactly this.
GPUGraphics Processing Unit
A special computer chip originally built for rendering video game graphics, which also happens to be extremely good at the kind of math AI models need. Most AI generation runs on a GPU rather than a regular processor (CPU) because it's dramatically faster at this specific job.
